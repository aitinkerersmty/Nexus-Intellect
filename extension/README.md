# Nexus Capture — Extensión Chromium

## Instalación

1. Abre la página de extensiones de Chrome o Edge.
2. Activa Developer mode.
3. Selecciona Load unpacked.
4. Elige la carpeta extension de este repositorio.

## Flujo

1. Abre una página de paper, DOI o PDF.
2. Abre Nexus Capture y pulsa Usar página actual.
3. Pulsa Abrir en Nexus.
4. Nexus abre el workspace con la URL lista para incorporarse al corpus.

La extensión guarda el valor pendiente en almacenamiento local de Chromium y no envía el contenido de la página a terceros.
